# Bitcoin

> Module 02 — Bitcoin

---

# Module Overview

This module provides an institutional-level study of Bitcoin.

Unlike introductory blockchain material, this module is centered on the **Bitcoin Whitepaper** and the protocol itself.

The objective is **not** to memorize Bitcoin.

The objective is to understand:

- Why Bitcoin works
- How Bitcoin works
- Which assumptions Bitcoin makes
- Which trade-offs Bitcoin accepts
- Which problems Bitcoin solves
- Which problems Bitcoin intentionally leaves unsolved

Every Research Unit is based primarily on the original Bitcoin Whitepaper and supported by protocol documentation, Bitcoin Core implementation, and relevant Bitcoin Improvement Proposals (BIPs).

---

# Learning Objectives

After completing this module, readers should be able to:

- Read the Bitcoin Whitepaper without relying on secondary explanations.
- Explain Bitcoin from first principles.
- Understand Bitcoin's consensus mechanism.
- Explain the UTXO model.
- Analyze Bitcoin transactions on-chain.
- Understand the economic incentives behind Bitcoin.
- Interpret Bitcoin protocol behavior using primary sources.

- Bitcoin Core Documentation

# Expected Outcome

After completing this module, readers should be able to read Bitcoin technical documents directly and understand protocol behavior without depending on simplified explanations.

The emphasis is on evidence-based research, protocol-level understanding, and institutional-quality analysis rather than investment narratives or popular summaries.
