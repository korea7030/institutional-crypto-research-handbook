SOURCE_REGISTRY.md

Institutional Source Registry

Version 1.0

⸻

Purpose

This registry defines the approved categories of sources used throughout the handbook.

It establishes a common reference framework for all contributors.

⸻

Source Hierarchy

Tier 1 — Primary Sources

* Official protocol documentation
* Whitepapers
* BIPs
* EIPs
* Protocol specifications

Highest authority.

⸻

Tier 2 — Academic Sources

* Peer-reviewed journals
* Conference papers
* University publications

⸻

Tier 3 — Protocol Implementations

* Official client repositories
* Reference implementations
* Source code

⸻

Tier 4 — Institutional Research

Examples include:

* Glassnode
* CryptoQuant
* Coin Metrics
* Artemis
* Messari

Used for interpretation, not protocol definition.

⸻

Tier 5 — Community Research

* Technical blogs
* Independent researchers
* Community analyses

Useful for generating hypotheses.

Requires independent verification.

⸻

Citation Identifier

Every frequently used source receives a stable identifier.

Examples

REF-BTC-WP-001

REF-ETH-WP-001

REF-EIP-1559

REF-GLASSNODE-001

REF-COINMETRICS-001

Identifiers remain stable across the repository.

⸻

Source Quality Rules

Higher-tier sources override lower-tier interpretations.

Conflicting sources must be documented transparently.

⸻

Registry Maintenance

The registry is reviewed periodically to ensure that referenced sources remain authoritative and current.

Deprecated sources are retained with historical notes when necessary.
