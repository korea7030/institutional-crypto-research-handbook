## 1. Learning Objectives

- Define evidence categories.
- Prioritize primary sources.
- Build multi-source evidence packets.

## 2. Executive Summary

`RESEARCH_STANDARD.md` requires primary sources first and states that evidence should be gathered from multiple independent sources whenever possible.[^ref-rs]

`RESEARCH_FRAMEWORK.md` lists onchain data, official documentation, protocol specifications, academic literature, market structure, and macro environment as core evidence categories.[^ref-rf]

`RESEARCH_PLAYBOOK.md` operationalizes this into protocol, onchain, market, and macro buckets, and explicitly warns against relying on a single category.[^ref-rp]

## 3. Collection Standard

Good evidence collection aims for:

- source independence,
- source traceability,
- category diversity,
- relevance to the actual question asked.

## 4. Common Failure Modes

- one-source dependence,
- using commentary as if it were primary evidence,
- collecting only evidence that supports the first hypothesis.

## 5. Institutional Thinking

- Evidence collection should widen possibility space before narrowing it.
- The purpose is not to gather more words. It is to gather more independent constraint on reality.
